# פרויקט הקורס: פלטפורמת אירועים לצלמים ולקוחות

זהו המאגר שתעבדי בו לאורך כל הקורס. בכל מפגש הוא גדל.

- **הקמת סביבה:** `SETUP.md`
- **לפני כל push:** `python -m tools.check`
- **הגשה:** ענף לכל מפגש (`lesson04`, `lesson05`, ...), push, וקישור למאגר ב־Teams.
- **הכלל היחיד לבדיקות:** בודקות את הדרישה, לא את המימוש שלכן. הבדיקות מייבאות רק את המודול שהמפגש מציין.
